BlueTunes for Windows 11 (x64)

Extract the ZIP, then double-click BlueTunes.exe. No installer, administrator
access, Rust, Python, or separate audio codecs are required.

Use Add music folder or Add files to import MP3 and FLAC music. Your audio stays
where it is. The executable can be moved independently of the source checkout.
Library and playback settings are saved in %LOCALAPPDATA%\BlueTunes.
To update, close BlueTunes and replace the executable with the newer download.
To uninstall, delete the extracted app; delete the data folder only if you also
want to erase your library, playlists, and settings. Music files are unaffected.

This build is unsigned. Windows may display a SmartScreen warning. Check that
you downloaded it from https://github.com/rpflug/BlueTunes/releases and verify
the SHA-256 checksum if needed. Follow your organization's security policy.

An audio output device and an OpenGL 2.1-compatible graphics driver are required.
Launch BlueTunes.exe --visualizer to open directly in visualizer mode.

Project and issue reports: https://github.com/rpflug/BlueTunes
